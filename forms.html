Form Inputs & Usage

Form elements allow users to input and select data. Consistent styling helps users recognize inputs, and clear labels and feedback ensure accessibility. All form controls are styled with common padding and borders using design tokens, and include states for focus and validation feedback.

Text Input

A standard text field for user input. It should be accompanied by a label for clarity. Use placeholder text to hint at the expected content, and ensure the text is legible against the input background.

<label for="input-id">Field Label</label>
<input type="text" id="input-id" class="form-control" placeholder="Type here..." />

Select Dropdown

A dropdown allows users to select one option from a list. Like inputs, it should have an associated label. Keep the default option (if any) clear and concise, and ensure the control is wide enough to show the content of options.

<label for="select-id">Choose an option</label>
<select id="select-id" class="form-control">
  <option value="">-- Select --</option>
  <option value="1">Option One</option>
  <option value="2">Option Two</option>
</select>

Checkboxes & Radio Buttons

Checkboxes allow users to select multiple options, while radio buttons allow a single selection from a group. Both should include clear labels and be grouped logically. Clicking the label toggles the input, improving usability.



<label><input type="checkbox" name="subscribe" /> Subscribe</label>
<label><input type="radio" name="choice" /> Option A</label>
<label><input type="radio" name="choice" /> Option B</label>

Error State

When a form field has invalid input or is required and not filled, an error state provides feedback. Use a clear message and a distinct color (e.g., red) to highlight the field. Ensure that the error color is accessible (consider color contrast) and supplemented by an icon or text for clarity if possible.

Please enter a valid email.

<label for="email">Email</label>
<input type="email" id="email" class="form-control form-control--error" />
<p class="error-message">Please enter a valid email.</p>
