Single Value (KPI) Charts

Highlight key metrics for at-a-glance understanding.

Example: Net Promoter Score (NPS)

Current NPS Score

+48

Top 5% in Industry

Usage Guidelines

When to Use

  • To highlight a single, critical metric such as revenue, user count, or uptime.
  • When the user needs quick, at-a-glance information.
  • For dashboard headers where summary KPIs appear above detailed charts.

When Not to Use

  • When multiple values need comparison — use bar, line, or pie charts instead.
  • For detailed trend analysis — use line/area charts.
  • When context is required (e.g., changes over time).

Best Practices

  • Use high contrast and large font size for readability.
  • Place KPIs consistently across dashboard layouts.
  • Use semantic colors to represent meaning (green = positive, red = warning).
  • Limit KPI widgets — avoid using more than 3–5 in one section.
