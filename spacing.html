Spacing Scale & Guidelines

Consistent spacing scale using CSS custom properties. Based on 4px increments for visual harmony and rhythm.

Spacing Scale

--space-1 4px
--space-2 8px
--space-3 12px
--space-4 16px
--space-5 20px
--space-6 24px
--space-8 32px
--space-10 40px
