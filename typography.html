Type Scale & Guidelines

Titles use a serif typeface for a strong, authoritative look, while body text uses Poppins for readability. Variables are defined in :root.

Heading 1

Variable: --fs-h1

Heading 2

Variable: --fs-h2

Heading 3

Variable: --fs-h3

Body text uses --fs-body. Keep line length around 60–80 characters. Ensure sufficient contrast against the background.

Weights: Regular (400), Medium (500), Semibold (600), Bold (700)

Labels: Form Label / Axis Label

Usage Notes

  • Use H1 for page titles, H2 for major sections, and H3 for card titles.
  • Body copy should remain at --fs-body for readability.
  • Avoid more than two font families. System stack fallback is provided.
  • For charts (Project 2), use H3 for chart titles and Label size for axis labels & legends.
