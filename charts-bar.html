Usage Guidelines

When to Use

  • Grouped Bar: To compare individual values side-by-side (e.g., sales per month).
  • Stacked Bar: When the total value is as important as its parts (e.g., total revenue split by product).
  • Horizontal Bar: When category labels are long or when ranking items (e.g., Top 5 Products).

Best Practices

  • Start at Zero: Always start the y-axis at 0 to avoid distorting the data comparisons.
  • Sorting: Sort horizontal bars by value (largest to smallest) to make ranking clear.
  • Limit Categories: Avoid comparing more than 5-7 groups at once to keep the chart readable.
  • Consistent Colors: Use the same color for the same category across all charts.
