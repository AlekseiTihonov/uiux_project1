Usage Guidelines

When to Use Line Charts

  • Showing trends over continuous time.
  • Comparing multiple trend lines.
  • Highlighting peaks, valleys, and direction of change.

When to Use Area Charts

  • Visualizing cumulative totals.
  • Emphasizing magnitude while still showing a trend.
  • Comparing stacked values across time.

Best Practices

  • Use consistent time intervals for accuracy.
  • Avoid too many overlapping lines — limit to 3–5 series.
  • Ensure high contrast between line color and background.
  • Use tooltips or labels to show exact values when possible.
