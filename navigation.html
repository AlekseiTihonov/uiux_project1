Navigation Patterns

Navigation components help users understand where they are in the dashboard and how to move between sections. This page documents three core patterns: a top navigation bar, breadcrumbs, and a sidebar menu.

Top Navigation Bar

A top navigation bar is placed at the top of the application. It usually contains the product name on the left and main links or controls on the right.

Ecovision
Overview Reports Settings 
<div class="top-nav">
  <span class="top-nav__logo">Ecovision</span>
  <nav aria-label="Main navigation">
    <a href="#">Overview</a>
    <a href="#">Reports</a>
    <a href="#">Settings</a>
  </nav>
</div>

Breadcrumbs

Breadcrumbs show the user's current location in the site hierarchy. All but the last item are links; the last item represents the current page.

Home > Analytics > Sales 
<nav aria-label="Breadcrumb">
  <ol class="breadcrumb">
    <li><a href="#">Home</a></li>
    <li><a href="#">Analytics</a></li>
    <li aria-current="page">Sales</li>
  </ol>
</nav>

Sidebar Navigation

A sidebar navigation provides a persistent menu on the side of the dashboard. It is useful for switching between major sections such as Dashboard, Reports, and Settings.

Sidebar Navigation
  • Dashboard
  • Reports
  • Settings
<aside class="ds-sidebar">
  <nav aria-label="Sidebar navigation">
    <ul>
      <li><a href="#">Dashboard</a></li>
      <li><a href="#">Reports</a></li>
      <li><a href="#">Settings</a></li>
    </ul>
  </nav>
</aside>
