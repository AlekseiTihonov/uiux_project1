Usage Guidelines

Tooltip Best Practices

  • Keep tooltip text short and descriptive
  • Use tooltips for supplementary information only
  • Ensure tooltips are accessible via keyboard navigation
  • Test tooltips on different screen sizes
  • Use consistent positioning throughout the application

Badge Usage

  • Use badges for non-critical status information
  • Choose colors that match the semantic meaning
  • Keep badge text concise (1–3 words)
  • Ensure sufficient color contrast for accessibility
