Card Components

Cards group related information into a clear, structured container. They help organize dashboards by creating consistent content blocks with padding, borders, and optional actions.

Basic Card

Use basic cards to present short text content or grouped information.

Card Title

This is a simple card with a title and text content.

<div class="card">
  <h4>Card Title</h4>
  <p>Card content...</p>
</div>

Usage Guidelines

  • Use for small, focused content groups.
  • Do not overload a card with too much text.
  • Keep spacing consistent inside the card.

Card with Image

Use image cards when visual context improves understanding.

Card Heading

Supporting text for the image.

Usage Guidelines

  • Use images only when meaningful to the content.
  • Ensure all images include descriptive alt text.
  • Keep images responsive and aligned to the card layout.

Card with Actions

Use action cards for content that requires user decisions.

Card Title

Content that leads to actions appears here.

Usage Guidelines

  • Place actions at the bottom of the card for consistency.
  • Use a primary button for the main action.
  • Do not overload the card with too many actions.
